A default tab menu can be defined in the app configuration and can be overwritten dynamically as required. Alternatively, the configuration can be left blank and all tab menus set by the website. The visibility of the tab menu can also be toggled dynamically at runtime.

## Implementation guide

### Select a tab

<MedianLogo />
<CodeGroup>
  ```javascript JavaScript 
  median.tabNavigation.selectTab(1); 
  ```
</CodeGroup>

**Note:** Tabs are 0-indexed, so `median.tabNavigation.selectTab(1)` selects the second tab.

### Deselect all tabs

<MedianLogo />
<CodeGroup>
  ```javascript JavaScript 
  median.tabNavigation.deselect(); 
  ```
</CodeGroup>

### Set or change the tab buttons

<MedianLogo />
<CodeGroup>
  ```javascript JavaScript
  var tabItems = [{
                "icon": "fas fa-cloud", //optional
                "label": "Tab 1",
                "url": "javascript:console.log('You selected tab 1')"
            }, {
                "icon": "fas fa-globe", //optional
                "label": "Tab 2",
                "url": "javascript:console.log('You selected tab 2')"
            }, {
                "icon": "fas fa-users", //optional
                "label": "Tab 3",
                "url": "javascript:console.log('You selected tab 3')"
            }];
  median.tabNavigation.setTabs({'enabled': true, 'items': tabItems});
  ```
</CodeGroup>

### Hide the tab menu

<MedianLogo />
<CodeGroup>
  ```javascript JavaScript
  median.tabNavigation.setTabs({'enabled': false});
  ```
</CodeGroup>
