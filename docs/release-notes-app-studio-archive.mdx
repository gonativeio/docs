# 2025 Releases

## Aug 12 - Maintenance 🛠️

* Added Expand/Collapse button for app groups in your organization.

## Aug 5 - New Feature 🆕

* Released official support for Single Sign-On (SSO), allowing you to securely log in using your organization’s identity provider. Please contact the Median team to enable SSO for your organization.

## Jul 3 - New Feature 🆕

* Released new UI for App Studio with new features like Groups, App Tags, App Pinning to allow for a better organized app management. [Docs](/docs/app-studio-accounts#app-management)
* Added functionality to view a list of previously uploaded assets and delete/restore previous assets as required.

## Apr 25 - Bugfix 🐛

* Fixed issue with App Studio "Native Navigation" configuration not being imported via "Import from Existing App" functionality.

## Mar 12 - Maintenance 🛠️

* "Bottom Tab Bar" visual editor preview in "Native Navigation" tab now accurately displays the inactive icons and colors

## Mar 12 - New Feature 🆕

* Added option to specify the inactive bottom tab bar color for iOS in the "Bottom Tab Bar" tab within the "Native Navigation" tab

## Mar 6 - Bugfix 🐛

* Fix an issue with Bottom Tab Bar Inactive Icon not saving

## Feb 25 - New Feature 🆕

* "Top Navigation Bar" visual editor in "Native Navigation" tab now allows putting multiple nav bar items inside an Action Menu
* "Bottom Tab Bar" visual editor in "Native Navigation" tab now allows specifying tab bar icons based on inactive / active state

## Jan 8 - New Feature 🆕

* Added Android 15 option in simulator preview for Pixel 6, Pixel 6 Pro, Pixel 7, Pixel 7 Pro, Pixel 8, Pixel 8 Pro devices

# 2024 Releases

## Dec 4 - Bugfix 🐛

* Fixed unresponsive delete button on "Top Navigation Bar" and "Bottom Tab Bar" visual editors in "Native Navigation" tab

## Nov 13 - Bugfix 🐛

* Fixed an issue with Google Services config file missing warning immediately closing on rebuild requests

## Oct 29 - Bugfix 🐛

* Fixed issue with "Discard Changes" not restoring deleted Google Services configuration in "Build & Download" tab

## Oct 25 - New Feature 🆕

* Added hover tooltip animation for improved accessibility when using App Studio
* Added iPhone 16 Pro and iPhone 16 Pro Max devices with iOS 18 in simulator preview
* Added iOS 18 option in simulator preview for other iPhone and iPad devices

## Oct 23 - Maintenance 🛠️

* Added UI text fields to enter Auth0 plugin configuration
* Adjusted logic for "Advanced Mode" toggle in Native Plugin settings for improved user experience

## Oct 18 - Bugfix 🐛

* Fixed an issue with deleting "Link Behavior" rules on initial page load

## Sep 5 - Maintenance 🛠️

* Renamed "Claim App" to "Add to Account" and improved user experience for "Add to Account" functionality.
* Improved user experience for "Transfer Organization" functionality. Your app's icon and name will be displayed when selecting the target organization to transfer your app.

## Aug 21 - New Feature 🆕

* Added links to Release Notes in "Build & Download" tab
* Added "Rebuild on Save" toggle in simulator preview. This is enabled by default. When enabled, saving your changes in App Studio automatically rebuilds your app in the simulator preview. Disabling this will not automatically rebuild the app in the simulator preview when you save your changes.

## Aug 8 - New Feature 🆕

* Added "Install on device" button to the 'Build & Download' tab and Public Sharing Link. Now, you can more easily download and install the Android APK directly to your device by scanning a QR code.

## Aug 2 - Maintenance 🛠️

* Improvements to Chrome DevTools functionality for browser-based simulators

## Jul 16 - New Feature 🆕

* Added Pixel 8 and Pixel 8 Pro devices in simulator preview
* Added Android 14 option in simulator preview for Galaxy Tab S7 and Pixel 6, 6 Pro, 7, 7 Pro, 8, 8 Pro devices

## Jun 25 - New Feature 🆕

* You can now restart your app within the browser-based simulator without restarting the entire device.
* You can also stop the current simulator session to more quickly switch to a different device model or device type.

## Jun 10 - Maintenance 🛠️

* Improvements to backup preview display.

## Jun 5 - Maintenance 🛠️

* Improvements to language localization on the Interface tab. Contact our team to add support for additional languages.

## May 21 - Maintenance 🛠️

* Performance improvements for display of [custom icon](/docs/custom-icons) when previewing

## May 21 - Maintenance 🛠️

* Improvements to [Top Navigation Bar](/docs/top-navigation-bar) configuration editor

## May 9 - Bugfix 🐛

* Fixed an issue where a zero value was not valid for the Session Cookie Expiry under Website Overrides

## May 2 - New Feature 🆕

* Added support for custom [context menus](/docs/context-menu)

## Mar 1 - New Feature 🆕

* Add option "Import from existing app" on the "Build & Download" tab's "App Configuration" section. This allows importing selected app configuration sections from another app in your organization to your desired app.

## Feb 15 - New Feature 🆕

* Add option to customize iOS permission description text for microphone access on the Permissions tab

## Jan 22 - Maintenance 🛠️

* Added support for Activity Indicator customization

## Jan 19 - Maintenance 🛠️

* Renamed Link Handling - Internal vs External Links to [Link Behavior](/docs/internal-vs-external-links)
* Added `My Domain` option for Link Behavior - Pages to Trigger Rule. This will allow easier configuration of link handling behavior for your app's domain.

# 2023 Releases

## Nov 28 - New Feature 🆕

* Introducing In-App browser links. You can now define link handling rules so that set links open in an in-app browser. This helps improve the end-user experience and increases session time.

## Oct 30 - New Feature 🆕

* Hosted offline page functionality to create an app offline page based on a live URL. The App Studio will save the content at the specified URL and display this cached page when your app is offline and unable to access your website.
* This functionality can be used to provide an offline page that is seamless and completely white labeled to your app without needing to write standalone HTML/CSS.

## Oct 19 - New Feature 🆕

* Added iPhone 15 Pro and iPhone 15 Pro Max devices with iOS 17 in simulator preview.
* Added iOS 17 option in simulator preview for iPhone 11 Pro, 12, 13 Pro, 13 Pro Max, 14 Pro, 14 Pro Max devices

## Sep 22 - New Feature 🆕

* Specify the languages you wish your app to support on the Interface tab. Contact our team to add support for additional languages.

## Jun 27 - New Feature 🆕

* More granular permission for WebRTC applications to provide app-level permission for the microphone and/or camera rather than both. Found on the Permissions tab.

## Mar 24 - New Feature 🆕

* Custom iOS camera permission can now be set on Permissions tab to skip needing to customize this string in Xcode

## Mar 21 - New Feature 🆕

* NFC usage description can now be set on Permissions tab.
