searchable: true
---

You can add a native Share button to your [top navigation bar](/docs/top-navigation-bar) (Android ActionBar and iOS Navigation Bar). When users tap this button, the current page is shared using the native iOS or Android share menu. You can show the button only on specific pages, based on the page URL.
