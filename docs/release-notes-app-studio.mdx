# 2026 Releases

## Sep 3 - New Feature 🆕

**Two-Factor Authentication (2FA)**

* Added support for **Two-Factor Authentication (2FA)** using authenticator apps, with single-use backup codes available as an alternative sign-in method.
* Users can enable and manage 2FA from **My Account**, including setup, disabling 2FA, and generating new backup codes.
* Organization Owners can enforce **2FA across their organization** and view the 2FA status of organization members.
* Members who join or sign in to an organization that requires 2FA are guided through setup before gaining access.

## Jul 16 - Bugfix 🐛

* Fixed an issue where, in some scenarios, newly exported custom icons into App Studio might not appear immediately in the Custom icon picker, ensuring updated icons are available without requiring a page refresh.

## Jul 16 - New Feature 🆕

* Improved navigation for Native Plugin settings by introducing direct links to individual plugin configuration pages and ensuring URLs update correctly when opening plugin settings, making it easier to bookmark and share specific plugin configurations.

## Jul 10 - Maintenance 🛠️

* **Google Sign-In Configuration Improvements**: Simplified Google Sign-In setup for Social Login plugin by automatically generating required iOS configuration values and adding validation to help prevent common setup mistakes.

## Jul 9 - Maintenance 🛠️

**App Studio Design & Usability Improvements**

* Improved navigation between Organization and Account pages, including clearer access to account settings and automatic redirection to your active account and organization.
* Enhanced the mobile experience with improved sidebar behavior and a variety of interface refinements across App Studio.
* Refined app previews, color selection, notifications, and page layouts for a more consistent and polished experience.
* Improved role and permission handling to better reflect available actions throughout App Studio.

## Jul 7 - New Feature 🆕

* **Expanded Icon Library**: Updated App Studio's icon library to include the latest Font Awesome icons, giving you access to a wider selection of icons for your app.

## Jun 17 - Bugfix 🐛

* Improved simulator usability on Public Sharing Links by fixing scrolling for larger device previews and optimizing automatic scaling for tablets and responsive screen sizes.

## Jun 15 - New Feature 🆕

**2-up Simulator mode & Simulator Panel Improvements**

* Added a new 2-up Simulator mode that allows you to run two simulators side-by-side for easier cross-platform testing and comparison.
* Improved simulator panel responsiveness to better adapt across screen sizes and available workspace.
* Moved simulator options such as Auto-Rebuild, Debug Mode, and Auto-Restart into a new Settings menu in the simulator panel header for a cleaner and more organized interface.

## Jun 10 - Bugfix 🐛

* Fixed an issue that could prevent UDID device registration due to unresponsive "Register Device" button when opening a iOS device registration link with a pre-filled device identifier.

## Jun 5 - Maintenance 🛠️

**Performance Improvements**

* Reduced the amount of data loaded during initial page visits to improve overall App Studio performance.
* Improved page load times and responsiveness across App Studio.
* Optimized navigation between sections for a smoother user experience.
* Reduced bandwidth usage while maintaining existing functionality and workflows.

## May 29 - New Feature 🆕

**App Studio Design & Usability Improvements**

* Refreshed App Studio with updated colors, spacing, icons, buttons, and overall visual consistency.
* Improved responsiveness across desktop, tablet, and mobile devices.
* Enhanced the mobile experience with a new side navigation menu, floating simulator button, and improved input field readability.
* Added updated designs to the iOS Testers, App Store Connect, and Settings tabs within Organizations.
* Improved search functionality for faster navigation and discovery of settings.
* Enhanced the color picker experience, including improved drag interactions on mobile devices.

## May 28 - New Feature 🆕

* Added new simulator controls for testing app behavior directly in Simulator Preview, including ability to test dark/light theme switching, Face ID/Fingerprint ID, device shake, lock/unlock, iOS software keyboard toggle, and changing simulator location.

## May 12 - New Feature 🆕

* Added option to customize iOS permission description text for Photo Library access on the "Permissions" tab

## May 7 - New Feature 🆕

* Added a new "Google Developer Verification" section on "Build & Download" tab, allowing you to add the ADI registration snippet from your Google Play Console to enable App Device Integrity verification for your app

## Mar 31 - New Feature 🆕

* Now only Organization Owners have permission to Manage App Access.

## Mar 18 - Maintenance 🛠️

* Added validation for "Issuer ID" and "Key ID" in "App Store Connect" page in your organization. You will now receive an inline alert message if your IDs do not follow the required format, helping prevent configuration errors. [Docs](/docs/connecting-median-appstore-connect)

## Feb 27 - Maintenance 🛠️

* Added app identifiers validation for iOS Bundle ID in "Build & Download" tab. You will now receive an inline alert message if your iOS Bundle ID does not follow the required format, helping prevent configuration errors. [Docs](app-identifiers)

## Feb 26 - Bugfix 🐛

* Fixed an issue where the "Submit" button in "Contact Us" form was not responsive in some cases.

## Feb 10 - New Feature 🆕

* Added option to hide top and bottom navigation bars on scroll in the "Top Navigation Bar" and "Bottom Tab Bar" tab within the "Native Navigation" tab

## Feb 10 - New Feature 🆕

* Added option to enable Liquid Glass on iOS in the "Interface" tab [Docs](/docs/ios-liquid-glass)
