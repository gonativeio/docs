Replit is an AI-powered cloud development platform that lets you create full-stack applications using natural language prompts. It's designed for developers of all skill levels, from beginners to professionals, who want to build and iterate on web applications quickly using AI assistance.

This guide is for Replit users who are converting their web app into native iOS and Android apps using Median. We'll show you how to prompt Replit Agent to add and use our native features.

## Key features

- **Replit Agent:** Your AI project manager and developer rolled into one. Describe what you want, and Replit Agent handles everything from environment setup to writing full-stack code to deploying your app.
- **Full-stack development:** Create complete applications with frontend, backend, and database integration all in one platform.
- **npm package support:** The Replit Agent can install and manage npm packages automatically, which is how you'll add the Median JavaScript Bridge.
- **Instant deployment:** Deploy your web app with a single click and get a live URL (`your-app-name.replit.app`) that's publicly accessible.
- **Cloud-based IDE:** Build and run your applications entirely in the browser with no local setup required.

## How Median works

Median converts your Replit web app into a full-featured native mobile app. Your web app, built with Replit, runs inside a native "shell" that we provide. This shell "bridges" the gap between your web code and the device's native features, like push notifications, haptics, and biometric auth.

When you are ready to launch on iOS, you can connect your Apple Developer account in Median App Studio, set **Upload to App Store Connect** to **Automatic**, test the uploaded build in TestFlight, and submit it for App Review. You do not need to rewrite your Replit app in Swift, build it in Xcode, or upload with Apple Transporter for the standard publishing workflow.

## Frequently asked questions

### Can I turn a Replit web app into an iOS app?

Yes. Paste the public URL of your Replit app into the **Website URL** field in App Studio. Median wraps your web app in a native iOS and Android app, and you can try it right away in the App Studio simulator. To get started, follow [Tutorial: Build a Vault app with Replit and Median](/docs/getting-started-with-replit).

### Can I publish a Replit app to the App Store?

Yes. Connect your Apple Developer account in App Studio, set **Upload to App Store Connect** to **Automatic**, test the build in TestFlight, and submit it for App Review. You don't need to rewrite your app in Swift or build it in Xcode. See [Connecting App Store Connect](/docs/connecting-median-appstore-connect) and the [publishing guide](/docs/app-publishing), which also covers Google Play.

### Does Median work with `.replit.app` URLs?

Yes. Median accepts `.replit.app` URLs and custom domains. Paste the public URL of your Replit app into the **Website URL** field in App Studio. To publish your Replit app and find its public URL, see Replit's guide [Publish your app <Icon icon="arrow-up-right-from-square" size={12} />](https://docs.replit.com/build/publish-your-app).

### Do I need to rebuild my Replit app in React Native?

No. Your Replit codebase stays the same, and Median only needs the public URL of your app. See the [Median architecture overview](/docs/architecture) to learn how Median apps work.

### How is Median different from Replit's native mobile app workflow?

Replit Agent can build a separate mobile app with React Native or Expo. Median wraps your existing Replit web app in a native iOS and Android app instead:

- **One web codebase:** You don't rebuild the app in React Native or manage a second mobile project. The Median app loads your published Replit URL.
- **Web updates without a new binary:** Changes you publish in Replit appear in the app on the next load, without rebuilding or republishing your Median app.
- **Native features from JavaScript:** Use the [Median JavaScript Bridge](/docs/javascript-bridge) for push notifications, biometric authentication, haptics, and other native plugins, instead of adding and debugging React Native modules.

### Can I add push notifications to a Replit web app?

Yes. Add the Median JavaScript Bridge to your Replit project, then connect OneSignal to register users and send push notifications. See [Add push notifications to your Replit app](/docs/add-push-notifications-to-your-replit-app) for step-by-step instructions.

### Can I test haptics in a simulator?

No. Haptic feedback only works on a physical device, not in the App Studio simulator or a desktop browser. Install a test build with [Install iOS IPA](/docs/install-ios-ipa) or [Install Android APK](/docs/install-android-apk). See [Add haptic feedback to your Replit app](/docs/add-haptic-feedback-to-your-replit-app).
