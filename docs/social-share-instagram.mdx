You can share text and media directly to Instagram as an Instagram Reel or directly to the user's Feed.

## Implementation guide

### Checking for availability

Before sharing content, check whether Instagram is installed on the user’s device. Use the following JavaScript Bridge method:

<MedianLogo />
<CodeGroup>
  ```javascript JavaScript
  const { isInstalled } = await median.socialShare.instagram.isInstalled();
  ```
</CodeGroup>

### Sharing media

This plugin only supports media sharing as a `Blob` object. You can save a remote image as a `Blob` using the following code snippet.

<CodeGroup>
  ```javascript JavaScript
    fetch("url-to-image")
    .then(function(response) {
      return response.blob();
    })
    .then(function(blob) {
      // here the image is a blob
    });
  ```
</CodeGroup>

Other plugins from Median (such as the [Web Screenshot plugin](/docs/web-screenshot)) also export images as Blobs which can then be used with this plugin.

### Sharing to feed

Use the following JavaScript Bridge command to share an image directly to the Instagram Feed:

<MedianLogo />
<CodeGroup>
  ```javascript JavaScript
  median.socialShare.instagram.shareToFeed(blob);
  ```
</CodeGroup>

<Warning>
  **Direct feed sharing isn't available on iOS**

  On iOS, Instagram no longer supports direct sharing to the feed and presents the OS share dialog instead.
</Warning>

### Sharing to story or reels

Share images directly to Instagram Stories or Reels. This method supports optional sticker attachments and captions.

Run the following Median JavaScript Bridge command:

<MedianLogo />
<CodeGroup>
  ```javascript JavaScript
  median.socialShare.instagram.share(blob, { attachment: stickerBlob, captionText: 'Caption for Snapchat' });
  ```
</CodeGroup>
