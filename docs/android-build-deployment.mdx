# Overview

Building and deploying Android applications requires Android Studio and a structured approach to ensure optimal performance, smooth debugging, and a seamless QA and release process. Whether you're compiling your app from source, configuring localhost testing, managing Android App Bundles, or installing APKs, understanding the core steps in Android build and deployment is key.

# Key Aspects of Android Build & Deployment

## Building Android from Source

Compiling an Android app from source involves setting up the development environment, configuring dependencies, and ensuring compatibility with Android SDKs. Following best practices can help prevent build failures and improve performance.

📖 Learn more: [Build Android from Source](https://median.co/docs/build-android-from-source)

## Testing with Android Studio and Localhost

Developers often need to test their apps with a local backend before deployment. Configuring Android Studio to connect with a localhost website allows for real-time testing and debugging in a controlled environment.

📖 Learn more: [Android Studio with Localhost Website](https://median.co/docs/android-studio-with-localhost-website)

## Using Android App Bundles for Optimized Distribution

Google Play requires Android App Bundles (AAB) instead of APKs for app distribution. App Bundles help reduce app size and improve installation efficiency, offering a better user experience while APKs are optimal for testing and debugging.

📖 Learn more: [Android App Bundle](https://median.co/docs/android-app-bundle)

## Installing and Distributing APKs

For manual testing or distribution outside the Google Play Store, APK installation is necessary. Understanding how to generate, sign, and install APKs accelerates your testing and deployment processes.

📖 Learn more: [Install Android APK](https://median.co/docs/install-android-apk)
