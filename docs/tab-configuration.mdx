## Trigger JavaScript commands from tab menu options

To have your links trigger JavaScript commands, specify URLs in the Visual Editor with the following syntax (Option 1). Alternatively, you can set the URL with the JavaScript command directly in the JSON (Option 2).

<CodeGroup>
  ```javascript JavaScript
  /* Option 1 - Visual Editor */
  javascript: console.log("test");
  ```
</CodeGroup>

<CodeGroup>
  ```json JSON
  /* Option 2 - JSON */
  {
    "tabSelectionConfig": [
      {
        "id": "1",
        "regex": ".*"
      }
    ],
    "tabMenus": [
      {
        "items": [
          {
            "subLinks": [],
            "icon": "fa-home",
            "label": "Home",
            "url": "javascript:console.log('test')" //specify javascript commands like this
          },
          {
            "subLinks": [],
            "icon": "fa-search",
            "label": "Search",
            "url": "javascript:console.log('You selected tab 2. These tabs are only shown on the about page')"
          }
        ],
        "id": "1"
      }
    ],
    "active": true
  }
  ```
</CodeGroup>

A more complicated example is to click an element when it exists, otherwise load a new URL.

<CodeGroup>
  ```javascript JavaScript
  /* Option 1 - Visual Editor */
  javascript: if (
    typeof jQuery === "undefined" ||
    jQuery("#linkElement").length == 0
  )
    window.location = "http://example.com/target";
  else jQuery("#linkElement").click();
  ```
</CodeGroup>

<CodeGroup>
  ```json JSON
  /* Option 2 - JSON */
  {
    "tabSelectionConfig": [
      {
        "id": "1",
        "regex": ".*"
      }
    ],
    "tabMenus": [
      {
        "items": [
          {
            "subLinks": [],
            "icon": "fa-home",
            "label": "Home",
            "url": "javascript:if (typeof jQuery === 'undefined' || jQuery('#linkElement').length == 0) window.location = 'http://example.com/target'; else jQuery('#linkElement').click();"
          },
          {
            "subLinks": [],
            "icon": "fa-search",
            "label": "Search",
            "url": "javascript:console.log('You selected tab 2. These tabs are only shown on the about page')"
          }
        ],
        "id": "1"
      }
    ],
    "active": true
  }
  ```
</CodeGroup>
