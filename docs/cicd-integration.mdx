## Downloading source code and binaries

You can download app sources and binaries using the following curl commands. You will need to replace `{{ APP ID }}` with your app ID and `{{ API KEY}}` with the API key of your organization.

### Examples

**iOS source**

<CodeGroup>
  ```bash bash
  curl --location 'https://median.co/project/{{ APP ID }}/download/iosSource' --header 'x-api-key: {{ API KEY }}' --output /path/ios_source.tar.gz
  ```
</CodeGroup>

**Android source**

<CodeGroup>
  ```bash bash
  curl --location 'https://median.co/project/{{ APP ID }}/download/androidSource' --header 'x-api-key: {{ API KEY }}' --output android_source.tar.gz
  ```
</CodeGroup>

**Android APK**

<CodeGroup>
  ```bash bash
  curl --location 'https://median.co/project/{{ APP ID }}/download/apk' --header 'x-api-key: {{ API KEY }}' --output app-release.apk
  ```
</CodeGroup>

**Android AAB**

<CodeGroup>
  ```bash bash
  curl --location 'https://median.co/project/{{ APP ID }}/download/aab' --header 'x-api-key: {{ API KEY }}' --output app-bundle.aab
  ```
</CodeGroup>

## Frequently asked questions

<AccordionGroup>
<Accordion title="Where do I find my API key?" id="where-do-i-find-my-api-key">

The API key isn't accessible in Median App Studio. Contact us to retrieve the API key for your organization.

</Accordion>
<Accordion title="Where do I find my app ID?" id="where-do-i-find-my-app-id">

You'll find your app ID in the private app management link (for example, if you manage your app via `https://median.co/app/{{APPID}}/overview`, your app ID will be `{{APPID}}`).

</Accordion>
<Accordion title="Why can't I download the builds of my cloned apps?" id="why-can-i-not-download-the-builds-of-my-cloned-apps">

To download your app builds and source code, an app build has to be created. Builds aren't created when cloning an existing app, so you have to manually build the app from the **Build & Deploy** tab within Median App Studio.

</Accordion>
</AccordionGroup>
