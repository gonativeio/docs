This plugin allows you to share text and media directly to the Snapchat mobile app.

## Implementation guide

### Checking for availability

Before attempting to share content, check whether **Snapchat is installed on the user’s device** to prevent errors and improve the user experience.

Use the following JavaScript Bridge command:

<MedianLogo />

<CodeGroup>
  ```javascript JavaScript 
  const {isInstalled} = await median.socialShare.snapchat.isInstalled(); 
  ```
</CodeGroup>

### Sharing media

Snapchat media sharing only supports media in a `Blob` object. You can save a remote image as a `Blob` using the following code snippet.

<CodeGroup>
  ```javascript JavaScript
    fetch("url-to-image")
    .then(function(response) {
      return response.blob();
    })
    .then(function(blob) {
      // here the image is a blob
    });
  ```
</CodeGroup>

Other plugins from Median (such as the [Web Screenshot Plugin](/docs/web-screenshot)) also export images as Blobs which can then be used with this plugin.
