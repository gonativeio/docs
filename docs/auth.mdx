Median's Biometric Authentication Native Plugin provides a streamlined solution for integrating secure biometric authentication across both iOS and Android platforms. The plugin is documented for each platform, offering developers detailed, platform-specific instructions to implement reliable and efficient biometric authentication in your apps.

## Apple Face ID & Touch ID

Apple's Face ID and Touch ID provide seamless, secure user authentication through advanced facial recognition and fingerprint scanning technologies. By integrating Apple's LocalAuthentication framework, developers can easily enable Face ID and Touch ID in their apps, ensuring secure access while enhancing the overall user experience.

📖 Learn more: [Apple Face ID / Touch ID](/docs/apple-face-id-touch-id)

## Android Biometric

Android biometrics enable secure user authentication through fingerprint, facial recognition, or iris scanning, enhancing both security and user experience. By integrating Android's Biometric API, developers can easily add biometric authentication to their apps, ensuring sensitive data is protected while streamlining the login process for users.

📖 Learn more: [Android Biometric](/docs/android-biometric-auth)
