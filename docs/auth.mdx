Median's Biometric Authentication Native Plugin adds secure biometric authentication to your app on both iOS and Android. The plugin is documented for each platform, with platform-specific instructions for implementing biometric authentication in your app.

## Apple Face ID & Touch ID

Apple's Face ID and Touch ID provide secure user authentication through facial recognition and fingerprint scanning. The plugin uses Apple's LocalAuthentication framework to enable Face ID and Touch ID in your app.

Learn more: [Apple Face ID / Touch ID](/docs/apple-face-id-touch-id)

## Android biometric

Android biometrics enable secure user authentication through fingerprint, facial recognition, or iris scanning, improving both security and user experience. The plugin uses Android's Biometric API to add biometric authentication to your app, protecting sensitive data and making sign-in faster for users.

Learn more: [Android biometric](/docs/android-biometric-auth)
