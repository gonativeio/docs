# 2026 Releases

## Aug 25 - New Feature 🆕

* Public release of the Firebase Cloud Messaging (FCM) plugin

## Jul 29 - Maintenance 🛠️

* Refactored AppsFlyer conversion data

## Jul 24 - Maintenance 🛠️

* Added support for specifying which barcode types the scanner should detect. This allows you to target specific code formats when multiple barcode types are present in the scan area

## Apr 29 - New Feature 🆕

* Added separate login/logout methods and updated error callback format in [RevenueCat](/docs/revenue-cat) plugin

## Apr 27 - Bugfix 🐛

* Fixed [JWPlayer](/docs/jwplayer) view overlapping with system UI bars on Android 15+

## Apr 24 - Bugfix 🐛

* Fixed error result format in [JWPlayer](https://github.com/gonativeio/android-plugins/pull/1243) plugin to match documentation

## Apr 21 - Bugfix 🐛

* Fixed: Google Sign-In not prompting on Android 14 and below when no Google account is present on the device. Added fallback to legacy Google Sign-In API [Docs](/docs/social-login)

## Apr 20 - New Feature 🆕

* GeckoView plugin now supports file uploads via camera and file picker
* GeckoView plugin now supports WebRTC permission requests [Docs](/docs/geckoview)

## Apr 13 - New Feature 🆕

* Released JWPlayer plugin for advanced media playback. Supports initialize, play, seek, and Chromecast casting [Docs](/docs/jwplayer)

## Apr 13 - New Feature 🆕

* Released Salesforce Mobile Push SDK plugin [Docs](/docs/salesforce-marketing-cloud)

## Apr 13 - New Feature 🆕

* Released Clerk SDK plugin for authentication. Provides native sign-in and user management via the Clerk platform [Docs](clerk)

## Apr 13 - New Feature 🆕

* Added support for Google Pay in WebView

## Apr 2 - Maintenance 🛠️

* Minimum SDK version has been bumped to Android 7.0 (API 24)

## Mar 24 - New Feature 🆕

* Released Background Audio plugin for audio playback control with notification support [Docs](background-audio)

## Mar 5 - New Feature 🆕

* Added support for D1000 Deadbolts, lock resets and firmware updates [Docs](/docs/master-lock)

## Mar 2 - Bugfix 🐛

* Fixed pinch-to-zoom not working in Google Maps

## Feb 12 - Bugfix 🐛

* Fixed app crash when opening external links in GeckoView engine

## Feb 11 - New Feature 🆕

* Added support for AppsFlyer Unified Deep Linking [Docs](/docs/appsflyer)

## Feb 4 - New Feature 🆕

* Added support to hide all native navigation bars on scroll

## Jan 30 - Bugfix 🐛

* Fixed an issue where pressing back button on initial screen would put the app in background instead of quitting the app

## Jan 8 - New Feature 🆕

[HealthBridge](/docs/health-bridge) Added support for the following health parameters

* Blood Glucose
* Blood Pressure
* Body Fat
* Body Temperature
* Elevation Gained
* Heart Rate
* Heart Rate Variability
* Menstruation
* Nutrition
* Oxygen Saturation
* Respiratory Rate
* Resting Heart Rate
* Speed
* Total Calories Burned
* VO2 Max

## Jan 6 - Bugfix 🐛

* \[OneSignal Legacy] Fixed OneSignal initialization not completing

# 2025 Releases

## Dec 18 - New Feature 🆕

* \[RevenueCat Plugin] Added support for displaying paywall modals [Docs](/docs/revenue-cat)

## Dec 16 - New Feature 🆕

* Added new JS Bridge method to allow set webview zoom

## Dec 8 - Maintenance 🛠️

* Theme (dark, light) changes are propagated without needing to re-create the webview. Eliminating the flickers related to theme changes

## Dec 8 - New Feature 🆕

* Released AgeSafety plugin [Docs](age-safety)

## Dec 4 - Maintenance 🛠️

* Remaining UI dialogs were migrated to Material 3

## Nov 10 - New Feature 🆕

* Added `middleName` field to the Contacts plugin [Docs](native-contacts)

## Oct 29 - New Feature 🆕

* Released the WebAuthn plugin [Docs](passkey-authentication)

## Oct 23 - Maintenance 🛠️

* Upgraded GeckoView plugin's SDK version to the current latest stable version v144 to fix crash issue on Android 16 devices

## Sep 22 - Maintenance 🛠️

* Meta App Events plugin now supports SDK version 18
