# 2026 Releases

## Sep 4 - Bugfix 🐛

* Added the missing the HealthKit capability for IPA builds

## Aug 25 - New Feature 🆕

* Public release of the Firebase Cloud Messaging (FCM) plugin

## Jul 29 - Maintenance 🛠️

* Refactored AppsFlyer conversion data

## Jul 24 - Maintenance 🛠️

* Added support for specifying which barcode types the scanner should detect. This allows you to target specific code formats when multiple barcode types are present in the scan area

## Jun 16 - New Feature 🆕

* Public release of the Customer.io plugin

## May 14 - Bugfix 🐛

* Fixed an issue with [AppsFlyer](/docs/appsflyer) plugin's Unified Deep Linking (UDL) callback not being called

## Apr 23 - Bugfix 🐛

* Fixed `setStatusBarOverlay` JS bridge method not working (always used appConfig value)

## Apr 22 - New Feature 🆕

* Released JWPlayer plugin for advanced media playback. Supports initialize, play, seek, and Chromecast casting [Docs](/docs/jwplayer)

## Apr 14 - New Feature 🆕

* \[Background Audio] Show local push notification when app enters background during recording [Docs](/docs/background-audio)

## Apr 14 - New Feature 🆕

* Released Clerk SDK plugin for authentication. Provides native sign-in and user management via the Clerk platform [Docs](clerk)

## Apr 14 - New Feature 🆕

* Released Salesforce Mobile Push SDK plugin [Docs](/docs/salesforce-marketing-cloud)

## Apr 9 - Bugfix 🐛

* Fixed truncated toolbar text when bold text accessibility setting is enabled

## Apr 7 - Maintenance 🛠️

* \[Meta App Events] Updated Facebook SDK to version 18.0 [Docs](/docs/facebook)

## Mar 24 - New Feature 🆕

* Released Background Audio plugin for audio playback control with notification support [Docs](/docs/background-audio)

## Mar 19

* \[AppsFlyer] Added success/error response callbacks to `setCustomerUserId` and `logEvent` methods

## Mar 4 - Bugfix 🐛

* Fixed setZoom to also update viewport content width, enabling proper media query triggering [Docs](webview-zoom)

## Feb 24 - Bugfix 🐛

* Prevented OneSignal from showing "Open Settings" dialog when push permission is denied

## Feb 23 - Maintenance 🛠️

* Updated Braze SDK to version 14.0.1
* Fixed push notification deep link issues

## Feb 12 - Bugfix 🐛

* Fixed issue where JavaScript methods would not execute when an alert dialog was displayed

## Feb 11 - New Feature 🆕

* Added support for AppsFlyer Unified Deep Linking [Docs](/docs/appsflyer)

## Feb 10 - New Feature 🆕

* Added support for iOS Liquid Glass Design [Docs](/docs/ios-liquid-glass)

## Jan 14 - Bugfix 🐛

* Fixed an issue where contextual navbar maybe visible after viewing a PDF file

## Jan 8 - New Feature 🆕

[HealthBridge](/docs/health-bridge) Added support for the following health parameters

* Blood Glucose
* Blood Pressure
* Body Fat
* Body Temperature
* Elevation Gained
* Heart Rate
* Heart Rate Variability
* Menstruation
* Nutrition
* Oxygen Saturation
* Respiratory Rate
* Resting Heart Rate
* Speed
* Total Calories Burned
* VO2 Max

# 2025 Releases

## Dec 18 - New Feature 🆕

* \[RevenueCat Plugin] Added support for displaying paywall modals [Docs](/docs/revenue-cat)

## Dec 16 - New Feature 🆕

* Added new JS Bridge method to allow set webview zoom

## Dec 1 - Bugfix 🐛

* Fixed handling of `data://` URLs. They are always handled internally now.

## Oct 24 - Maintenance 🛠️

* `console.info` calls are properly shown in web console logs now

## Oct 10 - Maintenance 🛠️

* AppReviewPlugin now uses the new `StoreKit` framework to ask for app review

## Oct 2 - Maintenance 🛠️

* Minimum OS version has been bumped to iOS 15.5

## Sep 22 - Maintenance 🛠️

* Enabled compatibility with iOS 26 by disabling glass design. We are working to properly support the new design guidelines
