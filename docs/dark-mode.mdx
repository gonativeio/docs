You may add support for dark and light modes within your web content by making use of the `prefers-color-scheme` CSS media query. Your app sets this parameter to `light` and `dark` based on the current device mode, and will change it dynamically when the device mode changes.

You may add a control toggle within your web content to force light or dark mode in addition to following the device setting (Auto mode). Median will set a property on your webpage called `data-color-scheme-option` with the current app setting of `light`, `dark`, or `auto`. You can use the value of this property to set the state of said toggle.

<CodeGroup>
  ```javascript JavaScript
  // Force Light Mode
  // Always use Light styling irrespective of device mode
  if (navigator.userAgent.indexOf("median") > -1) {
    median.screen.setColorScheme("light");
  }

  // Force Dark Mode
  // Always use Dark styling irrespective of device mode
  if (navigator.userAgent.indexOf("median") > -1) {
    median.screen.setColorScheme("dark");
  }

  // Auto Mode
  // Set to Auto mode to follow the device mode (Light or Dark)
  if (navigator.userAgent.indexOf("median") > -1) {
    median.screen.setColorScheme("auto");
  }

  // Revert to Default
  // Revert to the default configuration set in the app (Light/Dark/Auto)
  if (navigator.userAgent.indexOf("median") > -1) {
    median.screen.resetColorScheme();
  }

```
</CodeGroup>

We recommend using CSS variables to define the desired colors in light mode versus dark mode.

For a live example that you can adapt for your own website, check out Median's [dark mode switcher CodePen example](https://codepen.io/gonative/pen/dyzLKQQ), or refer to [MDN's reference for the CSS light-dark() function](https://developer.mozilla.org/en-US/docs/Web/CSS/Reference/Values/color_value/light-dark/) for details and examples of implementing dark mode with CSS.
