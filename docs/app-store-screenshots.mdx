## App Store Connect

Apple only requires screenshots for the largest iPhone and iPad display sizes. App Store Connect's Media Manager automatically scales them down for smaller devices. For every optional size, see Apple's [screenshot specifications](https://developer.apple.com/help/app-store-connect/reference/screenshot-specifications).

### File format

- JPEG or PNG
- 72 dpi, RGB color
- Flattened, with no transparency

### iPhone

| Display size | Accepted sizes (portrait)        | Accepted sizes (landscape)       |
| ------------ | -------------------------------- | -------------------------------- |
| **6.9-inch** | 1320 x 2868 px or 1290 x 2796 px | 2868 x 1320 px or 2796 x 1290 px |

### iPad

Median apps are universal by default, which means they run on both iPhone and iPad. Because of this, you need to upload iPad screenshots as well.

| Display size | Accepted sizes (portrait)        | Accepted sizes (landscape)       |
| ------------ | -------------------------------- | -------------------------------- |
| **13-inch**  | 2064 x 2752 px or 2048 x 2732 px | 2752 x 2064 px or 2732 x 2048 px |

## Google Play

Google Play doesn't require specific screenshot sizes. Screenshots must meet these requirements:

- JPEG or 24-bit PNG, with no transparency
- Each side is at least 320 px and at most 3840 px
- The longest side is no more than twice the length of the shortest side

For more details, see Google's [preview assets guidelines](https://support.google.com/googleplay/android-developer/answer/9866151).

### Recommended screenshot sizes

| Device                          | Recommended sizes                                 |
| ------------------------------- | ------------------------------------------------- |
| **Phone**                       | 1080 x 1920 px or 1440 x 2560 px                  |
| **Tablet (7-inch and 10-inch)** | 1920 x 1200 px, 2048 x 1536 px, or 2560 x 1600 px |

### Other listing images

| Image               | Size                               |
| ------------------- | ---------------------------------- |
| **App icon**        | 512 x 512 px, without transparency |
| **Feature graphic** | 1024 x 500 px                      |
