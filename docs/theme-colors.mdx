## Overview

Theme Colors set the primary color used by the native elements of your app. On iOS this is the tint color, and on Android it is the accent color.

## iOS

Tint color will be used for all native elements such as [Native Navigation](/docs/native-navigation-overview) elements of your app.

You can learn more about the iOS tint color in the Apple Developer Documentation: [Apple Developer tintColor <Icon icon="arrow-up-right-from-square" size={12} />](https://developer.apple.com/documentation/uikit/uiview/tintcolor)

## Android

In material design, UI element color palettes generally consist of one primary and one accent color. This setting applies the primary color for any native elements of your app.

You can learn more about the accent color for Android in the Android Developer Documentation: [Android Developers Accent color <Icon icon="arrow-up-right-from-square" size={12} />](https://developer.android.com/design/ui/mobile/guides/styles/color#accent-color)
