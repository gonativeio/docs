---
title: "Theme Colors"
description: "Theme Colors allow you to set a Primary Color used for text fields and labels. This configuration setting also referred to as the Tint color for iOS and the Accent color for Android."
---

## iOS

Tint color will be used for all native elements such as [Native Navigation](https://median.co/docs/native-navigation-overview) elements of your app.

You can learn more about the iOS tint color in the Apple Developer Documentation: [Apple Developer tintColor](https://developer.apple.com/documentation/uikit/uiview/tintcolor)

## Android

In material design, UI element color palettes generally consist of one primary and one accent color. This setting applies the primary color for any native elements of your app.

You can learn more about the accent color for Android in the Android Developer Documentation: [Android Developers Accent color](https://developer.android.com/design/ui/mobile/guides/styles/color#accent-color)
